# Стиль кода

Python 3.12, PEP 8, автоформатирование Ruff. Спорить о стиле на ревью не нужно —
его решает инструмент.

## Инструменты

```bash
ruff format .            # обязательное автоформатирование
ruff check .             # линтер (правила в pyproject.toml)
mypy lsp_overlay         # строгая проверка типов
pytest --cov=lsp_overlay
```

Конфигурация — `pyproject.toml`. Линтер включён для `E, F, I, UP, B, SIM, N, C4, RET, ARG, PL`;
исключения точечные и прокомментированы в конфиге.

## Именование

| Что | Как | Пример |
| --- | --- | --- |
| классы, типы | `PascalCase` | `MappingSession`, `JumpTooLargeError` |
| функции, переменные | `snake_case` | `rotation_matrix`, `pending_fields` |
| константы | `UPPER_SNAKE_CASE` | `LENGTH_TOLERANCE`, `DEFAULT_MAX_JUMP` |
| булевы | `is_/has_/can_/should_` | `is_complete`, `verify_after_paste` |
| модули и пакеты | по смыслу, без `utils`, `common`, `misc` | `domain/movement.py` |

Сокращения допустимы только общепринятые (`id`, `url`, `rx`/`ry`/`rz` — имена полей игры).

## Функции и модули

- Функция — до 30–40 строк, вложенность — до 3–4 уровней.
- Цикломатическая сложность — до 10–15; выше — декомпозиция.
- Одна ответственность: имена модулей описывают слой (`domain`, `application`,
  `infrastructure`, `ui`).
- Магические числа — в именованные константы (`PAD_BUTTON_WIDTH`, `COUNTDOWN_SECONDS`).
- Неизменяемость по умолчанию: доменные сущности — `frozen dataclass` (`Pose`, `Settings`).
- Никакого мёртвого и закомментированного кода, «временных» флагов, `TODO` без задачи.

## Типизация

- `from __future__ import annotations` во всех модулях; аннотации обязательны у всех функций.
- `mypy --strict` для `lsp_overlay`. Исключения — только с комментарием и `# type: ignore[...]`.
- Публичные контракты — `Protocol` (порты) и `dataclass` (значения).

## Документация в коде

```python
def move(pose: Pose, direction: Direction, step: float, *, use_tilt: bool = True) -> Pose:
    """Сдвигает проп на ``step`` метров в направлении ``direction``.

    Сдвиг считается в локальных осях предмета и переводится в мировые координаты,
    поэтому при ``RZ = 90°`` кнопка «вперёд» уводит проп на запад.

    Raises:
        ValidationError: если шаг не положительный или не конечный.
    """
```

Docstring — первая строка в повелительном наклонении, затем детали и `Raises`, если
функция кидает ожидаемые ошибки.

## Qt

- Бизнес-логика в виджетах не живёт: они только собирают сигналы и зовут сценарии.
- Виджет не ходит в файлы и в Win32 напрямую — через `application` и порты.
- Эмодзи в интерфейсе запрещены: в части шрифтов они рисуются «квадратиками».
  Разрешены символы из Segoe UI/DejaVu: `↑ ↓ ← → ↖ ↗ ↙ ↘ ▾ ▴ ÷ × °`.
- Стили — один `STYLESHEET` в `ui/styles.py`; локальные `setStyleSheet` — только для
  приглушённого текста.

## Логи и ошибки

- `LOGGER = logging.getLogger(__name__)` в каждом модуле; уровни — осознанно.
- Ожидаемые ошибки — наследники `DomainError` с человекочитаемым текстом на русском.
- Ошибки не глотать: либо обработать, либо пробросить с контекстом.

## Локализация

Интерфейс и сообщения — по-русски, ед. число/род по смыслу. Технические идентификаторы
(поля `x`, `y`, `z`, `rx`, `ry`, `rz`) остаются латиницей, как в панели игры.
