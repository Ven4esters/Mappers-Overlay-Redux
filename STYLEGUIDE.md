# Стиль кода

Инструменты решают споры: `ruff format` (Black-совместимо, 100 символов),
`ruff check`, `mypy --strict`, Python 3.12.

## Именование

- классы и типы — `PascalCase`, функции и переменные — `snake_case`,
  константы — `UPPER_SNAKE_CASE`;
- булевы — `is_`, `has_`, `can_`, `should_`;
- без сокращений, кроме общепринятых (`id`, `url`, `px`, `dpi`);
- файлы и пакеты — по смыслу (`panel_automation.py`, а не `utils2.py`).

## Функции

- до 30–40 строк, вложенность до 3–4 уровней, сложность ≤ 10–15;
- одна ответственность, явные аргументы, никаких скрытых зависимостей;
- публичные функции и классы — с docstring по Google-стилю;
- магические числа — в именованные константы с единицами (`CLICK_DELAY_S`).

## Слои

```
ui/            PySide6: окна, вкладки, стили. Знает про application, не про Win32.
application/   сценарии: сессия, запись, порты. Не знает про Qt и ctypes.
domain/        чистая логика: поза, направления, форматирование. Без I/O.
infrastructure/ Win32, буфер обмена, файлы настроек. Реализует порты.
```

Зависимости идут только внутрь: `ui → application → domain`,
`infrastructure → application/domain`. Домен ничего не импортирует из соседних слоёв.

## Ошибки и логи

- своя иерархия от `AppError`: `DomainError` → `ValidationError`, `ParseError`;
  `ConfigError`; `ApplicationError` → `NotCalibratedError`, `PoseNotCapturedError`,
  `PanelRejectedError`, `CursorMovedError`, `InputError`, `ClipboardError`,
  `UnsupportedPlatformError`;
- в UI показываем текст для пользователя, в журнал пишем контекст;
- исключения не глотаем: либо обрабатываем, либо пробрасываем с контекстом;
- логи — JSON-строки с уровнем и именем логгера, без секретов и координат мыши.

## Тесты

- unit — на домен (математика направлений, форматирование, разбор чисел);
- integration — на автоматизацию панели через фейковый ввод и буфер: проверяется порядок
  «клик → Ctrl+A → Ctrl+C» и запись «буфер → клик → Ctrl+A → Ctrl+V»;
- UI — smoke-тесты на offscreen-платформе;
- тесты детерминированы: время и мышь — через фейки, без `sleep` в тестах.
