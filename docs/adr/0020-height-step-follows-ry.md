# ADR-0020: режим высоты шагает по локальной оси `Z` с учётом `RY`

Статус: принято (1.5.5). Дополняет ADR-0015 (там высота меняла только `Z`, углы
игнорировались).

## Контекст

ADR-0015 свёл режим высоты к простой подмене: `Num 8` → `ΔZ = +шаг`, `Num 2` →
`ΔZ = −шаг`, углы не учитывались. На предметах с `RY ≠ 0` это даёт шаг не по оси предмета,
а по мировой оси `Z`: предмет уезжает с линии поверхности.

Заказчик прислал расчёт и подтвердил, что правило работает:

```
Шаг 3.0 вдоль локальной оси Z
Δ_local = (0, 0, 3)
Δ_world = (3·sin 10°, 0, 3·cos 10°)
Δ_world = (0.520944533, 0, 2.954423259)
```

## Решение

`tilt=True`, клавиши «вперёд/назад» — шаг по локальной оси `Z`, повёрнутой на `RY`:

```
Ry(RY) = |  cos RY   0   sin RY |        Δ_local = (0, 0, ±1)
         |    0      1      0    |
         | −sin RY   0   cos RY |

ΔX = ±sin RY · шаг
ΔY = 0
ΔZ = ±cos RY · шаг
```

`+` — `Num 8` (вверх), `−` — `Num 2` (вниз).

Матрица поворота вокруг `Y` переводит `Z` в плоскость `X/Z` и оставляет `Y` неизменным —
это та же матрица `Ry` из стандартного набора элементарных поворотов
([Rotation matrix, Wikipedia](https://en.wikipedia.org/wiki/Rotation_matrix);
[Y-rotation](https://www.redcrab-software.com/en/Calculator/Matrices/4x4/Rotation-Y)).

## Свойства

* `RY = 0` → прежнее поведение: `ΔX = 0`, `ΔZ = ±шаг`.
* Длина шага равна шагу при любом `RY`: `sin² + cos² = 1`, поворот не растягивает вектор
  ([Rotation matrix](https://en.wikipedia.org/wiki/Rotation_matrix)).
* `Y` не меняется: «вверх/вниз» никогда не двигает вбок.
* `RX` и `RZ` на высоту не влияют: поворот вокруг `X` не меняет ось `Z` по длине, а `RZ`
  в формуле высоты не участвует (так же, как у диагоналей).
* Вверх и вниз — строго противоположные шаги по всем осям.

| `RY` | Шаг 1.0, `Num 8` |
| --- | --- |
| 0° | `ΔX 0, ΔZ +1.000` |
| 10° | `ΔX +0.174, ΔZ +0.985` |
| 37° | `ΔX +0.602, ΔZ +0.799` |
| 45° | `ΔX +0.707, ΔZ +0.707` |
| 90° | `ΔX +1.000, ΔZ 0` |

## Следствия

* В журнале и строке состояния у подъёма/спуска с `RY ≠ 0` пишутся два поля: `X` и `Z`.
* Предупреждение о наклоне (`RX`/`RY` ≠ 0) по-прежнему напоминает про `Alt`, но теперь
  высота учитывает `RY`, а не игнорирует его.
