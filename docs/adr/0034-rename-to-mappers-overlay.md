# ADR-0034. Переименование: Map Overlay Redux → Mapper's Overlay Redux

- Статус: принято
- Дата: 2026-11-19
- Версия: 1.12.0

## Контекст

Приложение называлось «Map Overlay Redux», хотя делает оно не карту, а оверлей для
мапперов: калибрует поля панели, читает позу предмета и двигает его шагами. Заказчик
переименовал продукт в **Mapper's Overlay Redux** — «оверлей маппера».

Название встречается в трёх разных ролях, и мешать их нельзя:

1. **видимое имя** — заголовок окна, `--help`, `--check-only`, письма в журнале, README;
2. **имена файлов и пакетов** — `.exe`, `.spec`, wheel, папка сборки;
3. **внутренние идентификаторы кода** — модуль `map_overlay`, переменные окружения.

## Решение

### Что переименовано

| Место | Было | Стало |
| --- | --- | --- |
| Видимое имя | Map Overlay Redux | Mapper's Overlay Redux |
| exe и папка сборки | `MapOverlayRedux.exe` | `MappersOverlayRedux.exe` |
| spec | `MapOverlayRedux.spec` | `MappersOverlayRedux.spec` |
| wheel | `map-overlay-redux` | `mappers-overlay-redux` |
| переменная профиля | `MAP_OVERLAY_HOME` | `MAPPERS_OVERLAY_HOME` |

Апостроф в имени оставлен только в тексте для людей: в именах файлов и пакетов он был бы
неудобен (кавычки в bat-скриптах, странные пути), поэтому там `MappersOverlayRedux`
без апострофа.

### Что осталось как есть

- **Модуль `map_overlay`** и все импорты. Это внутреннее имя: менять его — значит
  переписать 60+ файлов, сломать внешние ссылки на модуль и получить ноль пользы для
  пользователя. Переименование продукта не обязано переименовывать код.
- **Формат и расположение данных**: `config/settings.json`, `config/sizes.json`,
  `logs/overlay.log`, `logs/crash.log`. Папки `config` и `logs` не переезжают — обновление
  на 1.12.0 не требует переносить профиль.
- **Прежняя переменная `MAP_OVERLAY_HOME`** продолжает читаться. Приоритет у новой
  `MAPPERS_OVERLAY_HOME`; если заданы обе, используется новая. Так старые ярлыки и
  переносимые папки продолжают работать.

### О журнале изменений

Записи `CHANGELOG.md` до 1.12.0 сохраняют прежнее название: это история, и переписывать её
означало бы утверждать, что продукт всегда назывался иначе. В записи 1.12.0 сказано о
переименовании, а старое имя в прошлых записях читается как факт того времени.

## Последствия

- В заголовке окна, `--check-only`, `--help` и журналах — «Mapper's Overlay Redux».
- Сборка идёт по `MappersOverlayRedux.spec`; старую папку `dist\MapOverlayRedux` можно
  удалить, данные (`config`, `logs`) она не содержит.
- `.gitignore` игнорирует `*.spec` (PyInstaller создаёт их сам), поэтому у нового spec есть
  явное исключение `!MappersOverlayRedux.spec` — иначе файл не попал бы ни в репозиторий,
  ни в архив, и сборка на чистой копии сломалась бы.
- Тесты: `test_application_name_is_mappers_overlay` (имя), 
  `test_home_environment_variable_renamed_with_legacy_support` (новая переменная + старая),
  а прежние проверки spec/bat/README обновлены на новые имена.
- Если понадобится переименовать и модуль `map_overlay`, это отдельное решение с отдельной
  миграцией импортов — не часть этого ADR.

## Альтернативы

- **Переименовать всё, включая модуль и папки данных.** Дорого, ломает профили
  пользователей и внешние ссылки; пользы для человека за окном нет.
- **Оставить имя прежним, поменять только подпись в окне.** Тогда exe, spec, wheel и
  документация по-прежнему назывались бы «Map Overlay Redux» — то есть переименования нет.
- **Апостроф в именах файлов.** `Mappers'Overlay.exe` создаёт проблемы в bat-скриптах и
  путях, а на вид не отличается от варианта без него.
