# ADR-0024. Проверка кода и документации по инструкции

- Статус: принято
- Дата: 2026-11-19
- Владелец: @Ven4esters
- Пересмотр: 2027-11-19
- Версия: 1.8.0

## Контекст

Перед выпуском 1.8.0 код и документация сверены с
`docs/instruction-code-style-and-checks.md`: мёртвый код, уязвимости, утечки, чистота.
Формулы движения трогать нельзя — все шесть эталонов обязаны остаться зелёными.

## Что проверялось

- мёртвый код: собственный AST-скрипт (определения с ≤ 2 упоминаниями по
  `map_overlay` + `tests` + `tools` + `main.py`), затем подтверждение `grep -rn`;
- уязвимости: `bandit`, `pip-audit`, ручной разбор ctypes/хука/`subprocess`;
- утечки: `detect-secrets` по `git ls-files`, ручная проверка журналов на пути и
  координаты, размер файлов журнала и аварий;
- соответствие инструкции: слои, docstring, размеры функций, обработка ошибок, DoD.

## Решения

1. **Мёртвый код удаляется, а не комментируется.** Удалены `action_for_direction`,
   `Field.is_angle`/`ANGLE_FIELDS`, `POSITION_FIELDS`, `Pose.with_value`, `UNBOUND`,
   `WindowsInput.screen_size` (+`SM_CXSCREEN`/`SM_CYSCREEN`), `widgets.add_row`,
   `SettingsTab.hotkey_rows`/`set_hotkeys_enabled`. Публичными их никто не использовал:
   вызовов нет ни в приложении, ни в тестах. `_DIRECTIONS` и `DEFAULT_HOTKEYS` остались —
   их читают `Action.direction` и настройки.
2. **«Висячие» строки-литералы — не документация.** Двадцать модульных литералов после
   констант (`"""Порядок полей…"""`) в Python ничего не делают: атрибута `__doc__` у
   константы нет. Заменены комментариями `#` рядом с константой.
3. **Аварийное выключение перехвата приоритетнее заморозки.** Проверка заморозки в хуке
   выполняется только при включённом перехвате: иначе снятая галочка не возвращала
   клавиатуру до истечения `FREEZE_LIMIT_S`.
4. **В потоке хука — никакого дискового ввода-вывода и лишних вызовов Win32.** Сообщение
   «Хук забрал клавишу» переведено на `DEBUG`, определение активного окна выполняется
   только при записи новой привязки (`learning`). Низкоуровневый хук обязан отвечать
   быстро, иначе Windows снимает его сам.
5. **Ограниченные журналы.** `overlay.log` — `RotatingFileHandler` (2 МБ × 3),
   `crash.log` — поворот при старте (1 МБ + один прошлый файл). Журнал не растёт без
   предела, а прошлые данные не теряются.
6. **Атомарная запись настроек с `fsync`.** `tmp` + `flush` + `fsync` + `replace`:
   после сбоя питания файл остаётся целым. Секретов в настройках нет (координаты и
   клавиши), поэтому права файла не ужесточаются — это записано в docstring.
7. **Границы входных данных — на границе.** Точки калибровки ограничены
   `MAX_POINT_COORDINATE = 100 000` px, отрицательная `schema_version` отвергается:
   испорченный файл настроек не должен превращаться в клик за пределами экрана.
8. **Лицензии зависимостей проверяются своим скриптом.** `tools/check_licenses.py` читает
   метаданные установленных пакетов через `importlib.metadata` и блокирует сильный
   копилефт (GPL/AGPL), пропуская LGPL и MPL: на LGPL работает сам Qt. Внешний
   `pip-licenses` не нужен — меньше зависимостей, а правило покрыто тестами.
9. **`bandit` и `detect-secrets` — в CI.** `# nosec` допускается только вместе с причиной
   рядом (в `tools/bootstrap.py`: свои команды, шелла нет). `detect-secrets` сканирует
   только файлы из `git ls-files`, иначе шумят кеши `.mypy_cache`.

## Последствия

- Тестов стало 813 (было 793): заморозка против выключения перехвата, ротация журнала и
  файла аварий, ленивая проверка активного окна, границы точек и версии схемы.
- Код хука стал короче и явнее: съедание клавиши вынесено в `_swallow`, константы
  `HOOK_BLOCK`/`HOOK_PASS` вместо литералов `1`/`0`.
- Крупные методы сборки интерфейса разбиты: `MainWindow._build` → `_build_layout`,
  `_build_status_bar`, `_build_timers`, `_connect_signals`; `MovementTab._build` →
  карточки, шаг, режим, подсказки; `SettingsTab._build_hotkeys` → сетка и строка;
  `TaskRunner.submit` → `_spawn`.
- Формулы движения не менялись: `docs/FORMULAS.md` и эталоны остаются в силе.
