# ADR-0027. `RZ` поворачивает шаг наклонённой диагонали вокруг оси `Z`

- Статус: принято
- Дата: 2026-11-19
- Версия: 1.9.0

## Контекст

Заказчик прислал формулы для случая «заданы все три угла» — отдельно для пары `Num 9/1`
и для пары `Num 7/3`:

```
Num 9/1, L = шаг:
  X_new = X + L·[sin RY·cos RZ + sin RX·cos RY·sin RZ]
  Y_new = Y + L·[sin RY·sin RZ − sin RX·cos RY·cos RZ]
  Z_new = Z + L·[cos RX·cos RY]

Num 7/3, L = шаг/√2:
  X_new = X + L·sin RZ·cos RX
  Y_new = Y − L·cos RZ·cos RX
  Z_new = Z − L·sin RX
```

До 1.9.0 считалось (и было записано в документации), что `RZ` на диагонали не влияет:
все прежние эталоны сняты при `RZ = 0`, и этот вывод был обобщением без данных.

## Решение

Обе присланные формулы — это поворот уже известного шага (из ADR-0025/0026) вокруг
мировой оси `Z`:

```
Rz(RZ):  ΔX = x·cos RZ − y·sin RZ
         ΔY = x·sin RZ + y·cos RZ
         ΔZ = z
```

Проверка буквально по картинкам: при `RX = 30°`, `RY = 20°`, `RZ = 40°`, шаг 2:

- `Num 9`: `Δ = (+1.128, −0.280, +1.628)` — совпадает с формулой `Num 9/1`;
- `Num 3`: `Δ = (+0.787, −0.938, −0.707)` — совпадает с формулой `Num 7/3`.

Реализация: `_diagonal` считает вектор случая 2/3 и отдаёт его в `_rotate_z`.
При `RZ = 0` поворот не выполняется, поэтому все эталоны 1–8 остаются в силе.

## Что не меняется

- Без наклона (`RX = 0`) диагональ по-прежнему от `RZ` не зависит: формула заказчика для
  этого случая `RZ` не содержит, а `Num 9` без наклона уходил в `−Y`/`+Z` при любом `RZ`
  (эталоны 1, 2 сняты при `RZ = 0`, прямая проверка — тест
  `test_diagonal_without_tilt_does_not_depend_on_rz`).
- Прямые клавиши `Num 8/2/4/6` и режим высоты (`Alt`) считаются как раньше: у прямых
  `RZ` уже был, у высоты его нет.

## Последствия

- `RZ` у наклонённой диагонали меняет `X` и `Y`, `Z` и длина шага сохраняются.
- Тесты `test_diagonal_does_not_depend_on_rotation` и
  `test_diagonal_with_two_angles_does_not_depend_on_rotation` заменены на проверки
  поворота (`..._turns_the_step_around_z`, `..._turns_around_z`).
- Добавлены два эталонных теста — буквальная запись присланных формул:
  `test_image_formula_for_the_right_pair`, `test_image_formula_for_the_left_pair`.
- `docs/FORMULAS.md` (эталон 9), README, `CHANGELOG`, `docs/LESSONS.md` обновлены.
