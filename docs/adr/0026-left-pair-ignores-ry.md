# ADR-0026. При `RY ≠ 0` пара `Num 7/3` считается по формуле плоскости `Y/Z`

- Статус: принято
- Дата: 2026-11-19
- Версия: 1.8.2

## Контекст

Заказчик подтвердил формулы 1.8.1 («здесь всё верно») и прислал два изображения для
случая, когда заданы и `RX`, и `RY`:

```
Image-1, пара Num 9/1:  X_new = X + L·sin RY
                        Y_new = Y − L·sin RX·cos RY
                        Z_new = Z + L·cos RX·cos RY

Image-2, пара Num 7/3:  X_new = X
                        Y_new = Y − L·cos RX
                        Z_new = Z − L·sin RX
```

Image-1 дословно совпадает с формулой 1.6.2, которая уже стояла в коде и сходилась с
эталонами 4 и 5 (`RX = 55°, RY = 17°` и `RX = 41.5°, RY = 22.3°`, обе — `Num 9`).
Image-2 не содержит `RY` вовсе: это та же формула, что и для случая «только `RX`»
(в ней `L = шаг/√2`, см. ADR-0025).

## Решение

Случай «`RX ≠ 0`, `RY ≠ 0`» делится по паре клавиш:

- пара `Num 9/1` (`ax·ay = −1`) — формула 1.6.2 с `L = шаг` (без изменений);
- пара `Num 7/3` (`ax·ay = +1`) — та же формула плоскости `Y/Z`, что и при `RY = 0`:
  `ΔX = 0`, `ΔY = ay·(шаг/√2)·cos RX`, `ΔZ = ax·(шаг/√2)·sin RX`. `RY` на эту пару
  не влияет, длина шага остаётся `шаг/√2`.

Реализация: в `_diagonal` пара `Num 7/3` уходит в `_rx_diagonal` при любом `RY`.

## Последствия

- Глубина `X` у `Num 7/3` не меняется никогда (ни при `RY = 0`, ни при `RY ≠ 0`).
- Длина шага у пары `Num 7/3` равна `шаг/√2`, у пары `Num 9/1` — `шаг`. Это
  несимметрично, но так задал заказчик; в коде это записано в docstring `_diagonal`.
- Новый эталон `test_user_example_for_the_left_pair_with_two_angles`:
  `RX = 55°`, `RY = 17°`, шаг 3, точка `(−1849.342, 416.528, 128.826)` →
  `Num 7` = `(…, 417.745, 130.564)`, `Num 3` = `(…, 415.311, 127.088)`.
- Тест «длина шага при двух углах равна шагу» ограничен парой `Num 9/1`; для пары
  `Num 7/3` добавлен отдельный тест длины `шаг/√2`.
- `docs/FORMULAS.md` (эталон 8), README, `CHANGELOG`, `docs/LESSONS.md` обновлены.
