# ADR-0039. Скриншоты README собираются из настоящего окна

- Статус: принято
- Дата: 2026-11-19
- Версия: 1.14.1

## Контекст

README показывал версию 1.5.0: вкладка «Движение» (переименована в «Навигацию» в 1.13.0),
широкое окно (сужено до 640 в той же версии), кнопка «В форму» (удалена в 1.13.1), нет
мини-версии, нет строки предмета. Скриншоты рисовались руками и перестали соответствовать
коду, а заметить это было некому: ни глаз, ни тест картинку не проверяют.

Заказчик попросил обновить изображения и привести README в порядок.

## Решение

Картинки собирает `tools/make_screenshots.py` из того же кода, что запускает пользователь:

- окно создаётся как в бою — `MainWindow` с `AppContext`, только вместо мыши, хука и панели
  подставляются объекты в памяти (`DemoPanel`, `DemoCursor`, `DemoHotkeys`);
- каждая вкладка снимается целиком, вместе со строкой состояния, и сохраняется в `docs/`;
- мини-версия снимается после `set_mini(True)`;
- схема диагоналей (`docs/diagonal-rx.png`) рисуется `QPainter`-ом, но значения сдвигов берёт
  из `map_overlay.domain.movement.shifted`, поэтому картинка не может разойтись с формулами;
- масштаб съёмки — `QT_SCALE_FACTOR=2`: картинка вдвое крупнее логических пикселей и остаётся
  резкой на экранах с масштабом.

Тест `tests/test_docs_images.py` проверяет то, что вообще можно проверить без эталонных
картинок: все ссылки README ведут на существующие PNG, файлы действительно PNG, а точки схемы
совпадают с `shifted`.

## Последствия

- Переименовали вкладку или кнопку — пересобрали картинки одной командой, а не искали редактор.
- Вёрстка стала проверяемой: снимок вкладки при ширине 640 сразу показывает обрезанные справа
  кнопки. Именно так нашлись четыре дефекта: незаметное поле ввода (светлый текст на белом
  фоне), перенос заголовка, мини-окно, которое не сужалось до 380, и вылезающие за карточку
  строки «Размеров» и «Настроек».
- На каждый из этих дефектов добавлен тест (`test_every_tab_fits_window_width`,
  `test_mini_hides_item_picker_and_stays_narrow`, `test_window_title_does_not_wrap`,
  `test_theme_styles_text_fields`).
- Минус: картинки — бинарные файлы в репозитории, их обновление видно в диффе только по
  размеру. Поэтому рядом с каждым PNG в README сказано, какой командой он собран.

## Отвергнуто

- **Рисовать скриншоты в редакторе.** Так и получилось расхождение на четыре версии: рисунок
  не пересобирается вместе с кодом и не ловится ни тестом, ни сборкой.
- **Проверять картинки побайтово в CI.** Эталонный скриншот зависит от шрифтов и версии Qt —
  тест был бы красным на каждой машине и ничего не проверял.
