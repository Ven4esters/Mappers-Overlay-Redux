# ADR-0004: живой режим и управление с Numpad

## Контекст

Первая версия 2.0 (коммит `d2db3d0`) двигала проп только в оверлее: пользователь нажимал
кнопки, потом «Применить» — и лишь тогда видел результат в игре. Для точной подгонки
(«на сантиметр влево, теперь на два») это медленно: каждый шаг — это два клика.

Управление стрелками не годится: в клиенте они заняты камерой, а в панели LSP — полями.

## Решение

1. **Живой режим с копией.** Кнопка «Живой режим (копия)» нажимает клавишу копии (`C`),
   перечитывает позу уже копии и дальше пишет координаты на каждый шаг, без подтверждения.
   Оригинал не трогается: если что-то пошло не так, копию удаляют кнопкой «Убрать копию».
2. **`F` не нажимается сам.** По умолчанию каждый шаг только вставляет значения в поля —
   в игре видно предполагаемое место. Автоматическое подтверждение включается галочкой
   «Подтверждать F в живом режиме» и нигде больше.
3. **Numpad вместо стрелок.** `8/2/4/6` и `7/9/1/3` — восемь направлений, `0` — «Считать»,
   `5` — «Сохранить F», `Enter` — «Применить», `+`/`−` — шаг. Требуется включённый NumLock:
   без него Numpad шлёт навигационные клавиши.
4. **Клавиши забираются у игры хуком.** `WH_KEYBOARD_LL` возвращает `1` на клавишах Numpad:
   клиент их не получает, камера не крутится, редактор не «уезжает». Если хук поставить
   нельзя, остаётся опрос `GetAsyncKeyState` — клавиши видит и игра, о чём пишем в журнал.
5. **Один шаг — одно нажатие.** Кнопки оверлея двигают ровно один шаг (`step_once`), иначе
   объект поедет бесконечно: у кнопки нет события отпускания. Удержание клавиши двигает
   плавно, но с двумя страховками: стоп через 1.0 с без новых нажатий и предохранитель на
   300 шагов подряд.

## Последствия

- Живой режим работает в отдельном потоке (`LiveMover`), панель отвечает не мгновенно —
  «плавность» даёт непрерывная очередь шагов, а не частота нажатий.
- Хук снимается при выключении режима, закрытии окна и любой ошибке записи: Numpad не
  должен остаться забранным у игры.
- Ошибки записи не глотаются: текст попадает в строку состояния, режим останавливается.
