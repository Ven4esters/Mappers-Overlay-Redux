# ADR-0001. Слоистая архитектура и порты

**Дата:** 2026-11-22
**Статус:** принято

## Контекст

Прошлая версия была одним большим окном, которое само кликало по панели игры, читало буфер
обмена и считало координаты. Проверить математику без запуска Windows было нельзя, а баг в
движении тянул за собой баг в интерфейсе.

## Решение

Разделить код на четыре слоя с зависимостями строго внутрь:

```
ui → application → domain
         ↑
  infrastructure (реализует порты application)
```

- `domain` — чистые функции и значения: матрица поворота, направления, форматирование,
  проверки безопасности. Ни Qt, ни Win32, ни файлов.
- `application` — сценарии: `MappingSession` (что записать) и `FieldWriter` (как записать
  с проверкой). Работает с портами `GamePanelPort`.
- `infrastructure` — `ClipboardPanel`, `Win32InputBackend`, `SystemClipboard`, `ConfigStore`.
- `ui` — окно и вкладки; только собирает сигналы и зовёт сценарии.

## Последствия

- Математику и сценарии можно тестировать на Linux без Qt и без Windows: 139 тестов идут 2–3 с.
- Появилась возможность подменить панель на эмулятор (`tests/fakes.py`) и проверить весь путь
  «кнопка → клики → проверка записи» без игры.
- Цена: чуть больше файлов и один лишний слой при добавлении поля.
