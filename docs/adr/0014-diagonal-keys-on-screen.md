# ADR-0014: диагональные клавиши повторяют режим по экрану

> **Заменено в 1.5.1 (ADR-0016).** Направление «по экрану» сохранено, но величины
> компонент больше не фиксированные 45°: они берутся из угла наклона предмета
> (`ΔY = ay · cos RX`, `ΔZ = ax · sin RX`). При `RX = 45°` числа совпадают с таблицей ниже.

## Контекст

С версии 1.0 диагональные клавиши (`Num 7/9/1/3`) двигали предмет по осям мира:
`ΔX = ±шаг/√2`, `ΔY = ±шаг/√2`, с поворотом от `RZ`. Пользователь попросил убрать эти
направления: они дают то же самое, что прямые клавиши, только по диагонали, и на экране
путаются с прямыми.

Одновременно в 1.4.0 появился режим по экрану, где `Num 8/2/4/6` дают четыре диагонали
монитора. Пользователь сформулировал перенос так: «диагонали в обычном режиме дублируют
направления в ALT режиме» и расписал связки: `Num 9 = Alt+8`, `Num 7 = Alt+4`,
`Num 1 = Alt+2`, `Num 3 = Alt+6`.

## Решение

В обычном режиме (без `Alt`) диагональные клавиши дают те же четыре направления, что и
прямые клавиши в режиме по экрану:

```
ΔY = dy · step,  ΔZ = dx · step,  ΔX = 0
```

| Клавиша | `(dx, dy)` | `ΔY` | `ΔZ` | Экран | Как в режиме Alt |
| --- | --- | --- | --- | --- | --- |
| `Num 9` | `(1, −1)` | −0.707 | +0.707 | вверх-вправо | `Num 8` |
| `Num 7` | `(1, 1)` | +0.707 | +0.707 | вверх-влево | `Num 4` |
| `Num 1` | `(−1, 1)` | +0.707 | −0.707 | вниз-влево | `Num 2` |
| `Num 3` | `(−1, −1)` | −0.707 | −0.707 | вниз-вправо | `Num 6` |

(компоненты — доли шага; `dx`, `dy` уже нормализованы к единичному вектору)

Прямые клавиши `Num 8/2/4/6` не изменились: горизонтальный шаг с поворотом от `RZ`.

## Почему так, а не «диагональ по осям»

* Настоящие диагонали монитора — единственные направления, которых у прямых клавиш нет;
  прежние «диагонали» были их дублем в других координатах.
* Диагонали не зависят от `RZ`: они повторяют экранные направления, а экранные оси задаёт
  камера. Это закреплено тестом `test_diagonal_does_not_depend_on_rotation`.
* Длина шага сохраняется: `ΔY² + ΔZ² = шаг²`.

## Следствия

* Диагональный шаг уводит предмет с горизонтальной плоскости (меняется `Z`). Для «поднять
  и подвинуть по экрану» это то, что нужно; для ровной езды по земле — нет.
* В режиме по экрану диагональные клавиши по-прежнему отключены (см. 1.4.1): там те же
  направления уже висят на прямых клавишах, и дублировать их не нужно.
* Соответствие «вправо = `−Y`, вверх = `+Z`» верно для камеры, смотрящей вдоль `X`.
