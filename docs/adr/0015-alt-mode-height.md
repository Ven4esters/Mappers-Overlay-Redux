# ADR-0015: режим высоты по `Alt`

## Контекст

В 1.4.0 режим по `Alt` считал шаг в плоскости экрана: `Num 8/2/4/6` давали четыре
диагонали монитора, диагональные клавиши в этом режиме были отключены, а с 1.4.2 диагонали
переехали в обычный режим. На практике пользователю нужен был всего один эффект: поднимать
и опускать предмет, не трогая `X` и `Y`.

Пользователь попросил убрать прежнюю реализацию и сделать простой режим: при включении
`Alt` клавиши `Num 8` и `Num 2` меняют смысл с «вперёд/назад» на «вверх/вниз».

## Решение

При включённом режиме (`tilt=True` в домене) меняется только смысл «вперёд-назад»:

```
Num 8 (FORWARD) → ΔX = 0, ΔY = 0, ΔZ = +шаг
Num 2 (BACK)    → ΔX = 0, ΔY = 0, ΔZ = −шаг
```

Всё остальное работает как в обычном режиме:

* `Num 4/6` — `Y` ± шаг, с поворотом от `RZ`;
* `Num 7/9/1/3` — диагонали экрана (`ΔY = dy · шаг`, `ΔZ = dx · шаг`), от `Alt` и `RZ`
  не зависят;
* углы не меняются никогда.

Прежняя модель «плоскость экрана для четырёх прямых клавиш» удалена целиком, вместе с
запретом диагоналей в режиме.

## Почему так

* Одна понятная подмена: «вперёд» становится «вверх», остальное предсказуемо.
* `|ΔZ| = шаг` — ровно один шаг по высоте, без дробей `шаг/√2`.
* Нет зависимости от `RX`/`RY`/`RZ` — подъём работает на любом предмете.
* Диагонали не отключаются: пользователь ими пользуется, и в этом режиме они значат то же,
  что и без него.

## Следствия

* Подъём «вверх» клавишей `Num 8` конфликтует с привычкой «`Num 8` — вперёд», поэтому режим
  включается только явным нажатием `Alt` (или галочкой), а подпись на вкладке показывает,
  что сейчас делают клавиши: «8 ↑ вверх · 2 ↓ вниз».
* Прежние документы про плоскость экрана (ADR-0013) помечены как заменённые.
