# ADR-0005. Каталог предметов отдельным файлом, три габарита по отдельности

**Дата:** 2026-11-23
**Статус:** принято

## Контекст

Мапперу нужны габариты предмета — длина, ширина, высота — чтобы ставить объекты вплотную и
повторно использовать уже измеренные. Один замер даёт одну величину: чтобы получить три,
нужно либо мерить трижды, либо угадывать по проекциям. Список предметов должен переживать
перезапуск и искаться по названию: объект мог использоваться в прошлый заход, и его габариты
надо найти, а не мерить заново.

## Решение

- **Каждый габарит меряется отдельно.** В «Рулетке» есть выбор габарита (`Длина`, `Ширина`,
  `Высота`) и кнопка «В размер»: текущий замер из двух точек записывается в выбранную
  величину. Так маппер сам решает, что именно он сейчас измерил.
- **Оси.** `Длина` и `Ширина` считаются вдоль локальных осей предмета (обратная матрица
  поворота, ADR-0002), поэтому поворот пропа на 45° не превращает длину в диагональ.
  `Высота` берётся по мировой вертикали: для «сколько занимает по Z» наклон не важен.
С 2.7.0 этот габарит называется `Толщина` и означает толщину плиты (ADR-0008).
- **Хранение — отдельный файл** `objects.json` рядом с `settings.json`
  (`%APPDATA%\LSPMapperOverlay`), формат `{"version": 1, "objects": [...]}`.
  Настройки для этого не годятся: каталог растёт, правится независимо и не должен ломать
  `Settings`, если в нём окажется битая запись. Битые записи при чтении пропускаются, а
  нечитаемый файл целиком уходит в `objects.broken.json` — как у настроек.
- **Ключ — название** без учёта регистра и крайних пробелов. Повторное сохранение с тем же
  названием обновляет запись (перемеряли объект — значения заменились), а не плодит дубли.
- **Поиск** — подстрока без учёта регистра, порядок — по алфавиту; фильтрация живёт в домене
  (`Catalog.find`), интерфейс только показывает результат.

## Последствия

- Каталог — домен без Qt и файлов (`lsp_overlay/domain/catalog.py`), хранение — адаптер
  (`infrastructure/catalog_store.py`), в сессии он как источник правды для таблицы.
- Незавершённые предметы разрешены: можно сохранить только длину, ширина и высота останутся
  нулями. `ObjectSpec.is_complete` показывает, всё ли измерено.
- Ошибочные значения отсекаются в `ObjectSpec.__post_init__`: пустое название, отрицательная
  или нечисловая величина, больше 500 м.
- «Шаг = длина» из таблицы использует длину предмета; шаг по-прежнему ограничен настройками.
- Тесты: `tests/test_catalog.py` (домен и файл), `tests/test_ui.py` (форма, поиск, шаг,
  удаление, загрузка при старте).
