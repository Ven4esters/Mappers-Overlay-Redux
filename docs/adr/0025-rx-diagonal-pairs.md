# ADR-0025. Диагонали при `RX ≠ 0` считаются по парам клавиш

- Статус: принято
- Дата: 2026-11-19
- Версия: 1.8.1

## Контекст

Заказчик прислал две картинки с «правильными формулами при `RX = N°`» и указал, к каким
клавишам они относятся:

```
Image-1, Num 9 и Num 1:   X_new = X,  Y_new = Y − L·sin RX,  Z_new = Z + L·cos RX
Image-2, Num 7 и Num 3:   X_new = X,  Y_new = Y − L·cos RX,  Z_new = Z − L·sin RX
```

До 1.8.1 в случае «`RX ≠ 0`, `RY = 0`» обе пары считались одной формулой
`ΔY = ay·k·sin RX`, `ΔZ = ax·k·cos RX` (формула 1.5.4). Она совпадала с Image-1 для
`Num 9`, но расходилась с Image-2: у пары `Num 7/3` `sin` и `cos` стоят на других осях.

## Решение

Случай «`RX ≠ 0`, `RY = 0`» делится на две ветви по паре клавиш (`k = шаг/√2`, `ΔX = 0`):

```
Num 9 и Num 1 (ax·ay = −1):   ΔY = ay · k · sin RX,   ΔZ = ax · k · cos RX
Num 7 и Num 3 (ax·ay = +1):   ΔY = ay · k · cos RX,   ΔZ = ax · k · sin RX
```

Картинки задают ключ, смотрящий вправо, поэтому знаки берутся из `ax`/`ay`: картинка
описывает `Num 9` (вправо-вверх) и `Num 3` (вправо-вниз), а `Num 1` и `Num 7` — их
зеркала внутри своей пары. Проверка: `Num 9` = `(0, −L sin RX, +L cos RX)` совпадает с
Image-1 буквально, `Num 3` = `(0, −L cos RX, −L sin RX)` — с Image-2 буквально.

Случаи «наклона нет» (`RX = 0`) и «наклонены `RX` и `RY`» не менялись: картинки про них
ничего не говорят, а эталоны 1–6 сходятся.

## Последствия

- Длина шага у обеих пар по-прежнему `шаг/√2`: `sin² + cos² = 1`, то есть это поворот,
  просто на разный угол.
- `Num 9` и `Num 7` при `RX ≠ 0` больше не зеркальны по `Y`/`Z`; зеркальны клавиши внутри
  пары (`9 ↔ 1`, `7 ↔ 3`). Тест `test_diagonal_keys_are_mirror_symmetric` переписан на пары.
- Новый эталон `test_user_example_at_76_degrees`: `RX = 76°`, шаг 3, точка
  `(−1850.403, 416.221, 130.544)`:

  | `Num 1` | 418.279 | 130.031 |
