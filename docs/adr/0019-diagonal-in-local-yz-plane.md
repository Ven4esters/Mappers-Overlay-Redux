# ADR-0019: диагональ — поворот в плоскости `Y/Z`, `X` не меняется

Статус: принято (1.5.4), с 1.6.0 дополнено ADR-0021 (`RY` добавляет глубину `X` и сжимает
`Z`; при `RY = 0` формула ниже остаётся в силе дословно). Заменяет ADR-0018 (там шаг уходил в
плоскость `X/Z` и менял глубину, что противоречит контрольному примеру пользователя).

## Контекст

Контрольный пример пользователя, заданный как эталон:

```
P = (−1849.342, 416.528, 128.826),  RX = 37°,  шаг = 2.0
P' = (−1849.342, 415.676, 129.955)
```

`X` не меняется. Значит диагональ не может уходить в плоскость `X/Z`: там `X_new = X + Δx`,
и это противоречит эталону. Расчёт переносится в плоскость `Y/Z`.

## Формула

Поворот вокруг оси `X` оставляет компоненту `X` неизменной, а `Y` и `Z` поворачивает в
плоскости `YZ`; матрица ортогональна и сохраняет длины векторов
([Rotation matrix, Wikipedia](https://en.wikipedia.org/wiki/Rotation_matrix);
[X-rotation](https://www.redcrab-software.com/en/Calculator/Matrices/4x4/Rotation-X)):

```
Rx(θ) = | 1      0         0    |
        | 0   cos θ   −sin θ     |
        | 0   sin θ    cos θ     |
```

В плоскости `Y/Z` диагональ — это ось «вверх/вниз» (`Δz = ±шаг/√2`) плюс знак «влево/вправо»
(`ay`):

```
X_new = X
Y_new = Y + ay · (шаг/√2) · sin θ
Z_new = Z + ax · (шаг/√2) · cos θ
```

где `ax = ±1` — «вперёд/назад» (он же «вверх/вниз»), `ay = ±1` — «влево/вправо»,
`θ = RX`.

Проверка на эталоне (`шаг = 2`, `θ = 37°`, `Num 9`: `ax = +1`, `ay = −1`):

```
ΔY = −1 · (2/√2) · sin 37° = −0.851  →  Y = 416.528 − 0.851 = 415.677
ΔZ = +1 · (2/√2) · cos 37° = +1.129  →  Z = 128.826 + 1.129 = 129.955
X  = −1849.342 (не меняется)
```

Совпадает с эталоном (расхождение 0.001 — округление координат до миллиметра).

| Клавиша | `RX = 0°` | `RX = 37°` | `RX = 45°` | `RX = 90°` |
| --- | --- | --- | --- | --- |
| `Num 9` вверх-вправо | `Y 0, Z +0.354` | `Y −0.213, Z +0.282` | `Y −0.250, Z +0.250` | `Y −0.354, Z 0` |
| `Num 7` вверх-влево | `Y 0, Z +0.354` | `Y +0.213, Z +0.282` | `Y +0.250, Z +0.250` | `Y +0.354, Z 0` |
| `Num 1` вниз-влево | `Y 0, Z −0.354` | `Y +0.213, Z −0.282` | `Y +0.250, Z −0.250` | `Y +0.354, Z 0` |
| `Num 3` вниз-вправо | `Y 0, Z −0.354` | `Y −0.213, Z −0.282` | `Y −0.250, Z −0.250` | `Y −0.354, Z 0` |

(шаг 0.5 м)

## Свойства

* Наклон диагонали на экране равен `90° − RX`: при `RX = 45°` — привычные 45°, при
  `RX = 90°` — горизонталь, при `RX = 37°` — 53°.
* `X` (глубина) не меняется ни при каком угле: это поворот вокруг `X`.
* Длина шага в плоскости `Y/Z` равна `шаг/√2` — поворот не растягивает вектор
  ([Rotation matrix](https://en.wikipedia.org/wiki/Rotation_matrix)).
* `RZ` в формулу не входит: диагонали не крутятся вместе с поворотом вокруг вертикали.

## Следствия, о которых надо помнить

* Диагональ — это не «45° на экране», а луч, который поворачивается вместе с `RX`. При
  `RX = 0` он вертикален, при `RX = 90` — горизонтален.
* Величина шага по диагонали — `шаг/√2`, а не `шаг`: в плоскости `Y/Z` вектор повёрнут,
  а не удлинён. Если нужен полный шаг, компоненты умножаются на `√2` (тогда эталон
  пользователя перестанет совпадать).
* При отрицательном `RX` знак `sin` меняется, то есть клавиши «вправо/влево» меняются
  местами: это следствие формулы, а не отдельное правило.
