# ADR-0003: обмен с панелью LSP

## Контекст

Панель LSP — обычные поля ввода внутри игры. Другого API нет, поэтому обмен идёт так, как
это делает человек: клик по полю, `Ctrl+A`, дальше `Ctrl+C` для чтения или `Ctrl+V` для
записи. Пользователь отдельно попросил **не** нажимать `Enter` и `F`.

## Решение

- **Калибровка.** Пользователь задаёт точку экрана для каждого поля. Точки хранятся в
  `config/settings.json` и проверяются при старте: без всех шести полей запись запрещена,
  кнопки говорят, каких точек не хватает.
- **Чтение:** клик → пауза → `Ctrl+A` → пауза → `Ctrl+C` → пауза → чтение буфера.
- **Запись:** буфер ← отформатированное число → клик → пауза → `Ctrl+A` → пауза →
  `Ctrl+V` → пауза.
- **Только изменившиеся поля.** Сравнение с допуском `0.0005` (половина третьего знака):
  лишние вставки не нужны и только мешают.
- **Проверка.** После вставки поле перечитывается; при расхождении — одна повторная
  попытка, затем ошибка с ожидаемым и фактическим значением. Проверку можно отключить в
  настройках, если панель отдаёт значения с задержкой.
- **Защита мыши.** Если во время обмена курсор сдвинулся больше чем на 4 пикселя, он
  возвращается в точку поля и операция продолжается: клик всегда наводится на
  откалиброванную точку, промахнуться невозможно. (В 1.1.0–1.1.1 операция прерывалась,
  и после одного движения мыши ошибка не уходила до перезапуска — см. ADR-0006.)
- **Задержки** между шагами — в настройках (по умолчанию 60/50/50/80 мс). Это первое, что
  стоит увеличить, если панель «не успевает».

## Последствия

- Приложение зависит от разрешения экрана и DPI: включаем Per-Monitor V2, координаты
  кликов — физические пиксели.
- Оверлей не должен перекрывать поля панели, иначе клики попадут в оверлей.
- Без проверки записи возможен «тихий» отказ панели, поэтому проверка включена по умолчанию.
