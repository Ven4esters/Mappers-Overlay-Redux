# Действующие формулы сдвига (1.7.1, без изменений в 1.8.0)

Сводка «что считается сейчас» и история правок. Один источник истины для вопросов
«а какая формула правильная».

Обозначения: `шаг` — шаг из интерфейса (0.01–100 м), `ax = ±1` — клавиша «вперёд/назад»
(она же «вверх/вниз»), `ay = ±1` — «влево/вправо», `RX`/`RY`/`RZ` — углы предмета в градусах.

## Прямые клавиши `Num 8/2/4/6`

```
Δ = Rz(RZ) · (ax, ay) · шаг,   ΔZ = 0
```

Поворот: `+RZ` — против часовой. Длина шага — ровно `шаг`.

## Диагонали `Num 7/9/1/3` — три случая

| Случай | Формула | Длина |
| --- | --- | --- |
| `RX = 0` (наклона нет) | `ΔX = 0`, `ΔY = ay·шаг/√2`, `ΔZ = ax·шаг/√2` | `шаг` |
| `RX ≠ 0`, `RY = 0` | `ΔX = 0`, `ΔY = ay·(шаг/√2)·sin RX`, `ΔZ = ax·(шаг/√2)·cos RX` | `шаг/√2` |
| `RX ≠ 0` и `RY ≠ 0` | `ΔX = ax·шаг·sin RY`, `ΔY = ay·шаг·sin RX·cos RY`, `ΔZ = ax·шаг·cos RX·cos RY` | `шаг` |

`RZ` диагонали не крутит ни в одном случае. `RY` без `RX` диагональ не меняет.

## Режим высоты — `Alt` + `Num 8/2`

```
ΔX = ±шаг·sin RY,   ΔY = 0,   ΔZ = ±шаг·cos RY
```

`+` для `Num 8` (вверх), `−` для `Num 2` (вниз). `RX` и `RZ` не участвуют. Длина — `шаг`.

## Эталоны заказчика (проверены в игре)

```

2. Без углов, шаг 3.0, Num 9:

3. RX = 37°, RY = 0, шаг 2.0, Num 9:
```

## История правок диагоналей

| Версия | Что было | Чем плохо |
| --- | --- | --- |
| 1.4.x | плоскость экрана, диагонали не поворачивались | не учитывала наклон предмета |
| 1.5.0–1.5.1 | поворот на `RX` по «плоскости предмета» | на `RX = 37°` шаг съезжал |
| 1.5.2 | `(0, ay, ax)/√2` | не совпало с эталоном |
| 1.5.3 | плоскость `X/Z`, `ΔX = ±L/√2` | меняла глубину, эталон запрещал |
| 1.5.4 | плоскость `Y/Z`, `ΔX = 0`, `шаг/√2` | не учитывала `RY` |
| 1.6.0 | `RX` и `RY`, но `cos RY` только у `Z` | длина шага росла (откатано) |
| 1.6.1 | `cos RY` у `Y` и `Z`, `L = шаг/√2` | шаг короче нужного в `√2` раза |
| 1.6.2 | `L = шаг` | без наклона оставался один `ΔZ` — «вверх-вниз» вместо диагонали |
| 1.7.0 | формулы по случаям | случай «без наклона» уводил шаг в глубину `X` |
| 1.7.1 | случай «без наклона» — 45° в плоскости `Y/Z` | действует |
| 1.8.0 | формулы не менялись: аудит кода и документации (ADR-0024) | действует |

Подробности по каждой правке: `CHANGELOG.md` (записи по версиям), `docs/adr/` (решения и
причины), `docs/LESSONS.md` (разборы ошибок).
