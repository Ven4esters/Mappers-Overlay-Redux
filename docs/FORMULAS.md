# Действующие формулы сдвига (1.15.0)

Сводка «что считается сейчас» и история правок. Один источник истины для вопросов
«а какая формула правильная».

Обозначения: `шаг` — шаг из интерфейса (0.01–100 м), `ax = ±1` — клавиша «вперёд/назад»
(она же «вверх/вниз»), `ay = ±1` — «влево/вправо», `RX`/`RY`/`RZ` — углы предмета в градусах.

## Прямые клавиши `Num 8/2/4/6`

```
Δ = Rz(RZ) · (ax, ay) · шаг,   ΔZ = 0
```

Поворот: `+RZ` — против часовой. Длина шага — ровно `шаг`.

## Диагонали `Num 7/9/1/3` — по случаям и по парам

| Случай | Формула | Длина |
| --- | --- | --- |
| `RX = 0` (наклона нет) | `ΔX = 0`, `ΔY = ay·шаг/√2`, `ΔZ = ax·шаг/√2` | `шаг` |
| `RX ≠ 0`, `RY = 0`, пара `Num 9/1` | `ΔX = 0`, `ΔY = ay·(шаг/√2)·sin RX`, `ΔZ = ax·(шаг/√2)·cos RX` | `шаг/√2` |
| `RX ≠ 0`, `RY = 0`, пара `Num 7/3` | `ΔX = 0`, `ΔY = ay·(шаг/√2)·cos RX`, `ΔZ = ax·(шаг/√2)·sin RX` | `шаг/√2` |
| `RX ≠ 0` и `RY ≠ 0`, пара `Num 9/1` | `ΔX = ax·шаг·sin RY`, `ΔY = ay·шаг·sin RX·cos RY`, `ΔZ = ax·шаг·cos RX·cos RY` | `шаг` |
| `RX ≠ 0` и `RY ≠ 0`, пара `Num 7/3` | как случай «только `RX`»: `ΔX = 0`, `ΔY = ay·(шаг/√2)·cos RX`, `ΔZ = ax·(шаг/√2)·sin RX` | `шаг/√2` |

Без наклона (`RX = 0`) `RZ` диагональ не крутит. Как только наклон есть, `RZ`
поворачивает **готовый шаг** вокруг мировой оси `Z` — так выглядят формулы заказчика
для трёх углов (ADR-0027):

```
пара Num 9/1, L = шаг:
  ΔX = ax·L·(sin RY·cos RZ + sin RX·cos RY·sin RZ)
  ΔY = ax·L·sin RY·sin RZ + ay·L·sin RX·cos RY·cos RZ
  ΔZ = ax·L·cos RX·cos RY

пара Num 7/3, L = шаг/√2:
  ΔX =  ay·L·sin RZ·cos RX
  ΔY = −ay·L·cos RZ·cos RX
  ΔZ =  ax·L·sin RX
```

При `RZ = 0` эти строки превращаются в формулы из таблицы выше, поэтому все прежние
эталоны (там `RZ = 0`) остаются в силе. `RY` без `RX` диагональ не меняет.

Пары клавиш — это `Num 9`/`Num 1` (правая диагональ, `ax·ay = −1`) и `Num 7`/`Num 3`
(левая, `ax·ay = +1`). У них разная тригонометрия: при одном и том же `RX` первая пара
уходит вбок на `sin RX`, вторая — на `cos RX`. Поэтому `Num 9` и `Num 7` при `RX ≠ 0`
не зеркальны: зеркальны клавиши внутри пары (`9 ↔ 1`, `7 ↔ 3`).

`RY` — только для пары `Num 9/1`: у `Num 7/3` при любом `RY` работает формула плоскости
`Y/Z`, глубина `X` не меняется, длина шага остаётся `шаг/√2`.

## Режим высоты — `Alt` + `Num 8/2`

```
ΔX = ±шаг·sin RY,   ΔY = 0,   ΔZ = ±шаг·cos RY
```

`+` для `Num 8` (вверх), `−` для `Num 2` (вниз). `RX` и `RZ` не участвуют. Длина — `шаг`.

```

   (−1849.342, 416.528, 129.816) → (−1849.342, 414.407, 131.937)

2. Без углов, шаг 3.0, Num 9:
   (−1850.403, 414.979, 130.554) → (−1850.403, 412.858, 132.675)

3. RX = 37°, RY = 0, шаг 2.0, Num 9:
   (−1849.342, 416.528, 128.826) → (−1849.342, 415.677, 129.955)

5. RX = 41.5°, RY = 22.3°, шаг 3.0, Num 9:
   (−1849.342, 416.528, 128.816) → (−1848.204, 414.689, 130.895)

6. Alt, RY = 10°, шаг 3.0, Num 8:
   Δ = (0.520944533, 0, 2.954423259)

7. RX = 76°, RY = RZ = 0, шаг 3.0, пары 9-1 и 7-3:
   (−1850.403, 416.221, 130.544)
   Num 9 → (−1850.403, 414.163, 131.057)   Δ = (0, −2.058, +0.513)
   Num 1 → (−1850.403, 418.279, 130.031)   Δ = (0, +2.058, −0.513)
   Num 7 → (−1850.403, 416.734, 132.602)   Δ = (0, +0.513, +2.058)
   Num 3 → (−1850.403, 415.708, 128.486)   Δ = (0, −0.513, −2.058)

8. RX = 55°, RY = 17°, шаг 3.0, пара 7-3 (RY в формулу не входит):
   (−1849.342, 416.528, 128.826)
   Num 7 → (−1849.342, 417.745, 130.564)   Δ = (0, +1.217, +1.738)
   Num 3 → (−1849.342, 415.311, 127.088)   Δ = (0, −1.217, −1.738)

9. RX = 30°, RY = 20°, RZ = 40°, шаг 2.0 (проверка формул трёх углов):
   пара 9-1, Num 9 → Δ = (+1.128, −0.280, +1.628)
   пара 7-3, Num 3 → Δ = (+0.787, −0.938, −0.707)
```

Каждый эталон закреплён тестом — см. `tests/test_movement.py`.
