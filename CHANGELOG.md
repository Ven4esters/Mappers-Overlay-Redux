# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — SemVer.

## [1.0.0] — 2026-11-24

Первая версия Map Overlay Redux, собранная с нуля.

### Добавлено

- Калибровка шести полей панели LSP: `X`, `Y`, `Z`, `RX`, `RY`, `RZ`. Точка берётся по
  курсору после отсчёта 3 секунды, проверка — кнопкой «Показать».
- Запись значений в панель: клик по полю → `Ctrl+A` → `Ctrl+V`. Только изменившиеся поля.
- Чтение координат: клик по полю → `Ctrl+A` → `Ctrl+C`.
- Движение стрелками по восьми направлениям: вперёд (`X−`), назад (`X+`), влево (`Y−`),
  вправо (`Y+`), четыре диагонали.
- Проверка записи: после вставки поле перечитывается, при отказе панели — одна повторная
  попытка и понятное сообщение.
- Защита от движения мыши во время обмена с панелью (порог 4 пикселя).
- Окно с вкладками «Движение», «Калибровка», «Настройки», настройка задержек, знаков
  после запятой, шага и проверки записи.
- `run_overlay.bat` (окружение + запуск), `build_exe.bat` (сборка PyInstaller).
- `--check-only`: проверка окружения и настроек без открытия окна.
- Переменная `MAP_OVERLAY_HOME` для отдельного профиля `config/` и `logs/`.
- CI: ruff, mypy, pytest с покрытием, pip-audit.

### Известные ограничения

- При `RZ ≠ 0` стрелки двигают по мировым осям; правила для повёрнутых объектов ещё не
  заданы, оверлей предупреждает об этом.
- Наклоны `RX`/`RY` на движение не влияют.
